# 🎮 Rock Paper Scissors Game (C++)

A simple and interactive **Rock, Paper, Scissors** console game built using **C++**.  
The project demonstrates the use of functions, enums, loops, conditional statements, random number generation, and clean code organization.

---

## 📌 Features

- 🎮 Play against the computer.
- 🔢 Choose the number of rounds.
- 🎲 Random computer choices.
- 🏆 Displays the winner of each round.
- 📊 Shows game statistics at the end.
- 🎨 Colored console output (Windows Console).
- 🔄 Option to play again without restarting the application.

## 🎯 Game Rules

- 🪨 Rock beats Scissors.
- ✂️ Scissors beat Paper.
- 📄 Paper beats Rock.
- If both players choose the same option, the round ends in a Draw.

---

## 📸 Gameplay

```
How Many Rounds? 5

Round [1/5]

Your Choice:
[1] Rock
[2] Paper
[3] Scissors

Player Choice   : Rock
Computer Choice : Paper

Round Winner : Computer
```

```
===========================================
           Game Over
===========================================

Player Wins   : 2

Draws         : 0

Final Winner : Computer
```
